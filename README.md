# OSportMobile Lite

Веб-версия для участника: скачать событие из облака, отметиться, отправить
результат. Ничего не создаёт и не редактирует — только проходит.

## Что уже есть (каркас)

- Экран поиска события по номеру.
- Карточка найденного события: название, номер, организатор, сроки, КП, участники.
- Установка как приложение (manifest, иконки) и офлайн-оболочка (service worker).

## Чего ещё нет

- Скачивание события целиком (нужно действие `get` в облачной функции).
- Отметки: QR-сканер и GPS-кнопка.
- Отправка результата и очередь повторов.

## Запуск локально

```powershell
cd C:\Users\evsuj\AndroidStudioProjects\OSportMobileLite
powershell -Command "python -m http.server 8080"
```

Открыть `http://localhost:8080`. Service worker на `localhost` работает.

## Публикация на GitHub Pages

1. Репозиторий `SergeiEvsujkov/OSportMobileLite`, ветка `main`.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://sergeievujkov.github.io/OSportMobileLite/`.

Пути в файлах относительные, поэтому подкаталог в адресе не мешает.

## Что нужно от облака

Браузер не может ходить в функцию так, как это делает приложение: нужны
**CORS-заголовки** и ответ на `OPTIONS`. Пока их нет, поиск события покажет
понятную ошибку про CORS — это ожидаемо.

Следующие шаги на стороне функции:

1. Разрешить origin `https://sergeievujkov.github.io` (и `http://localhost:8080` для разработки).
2. Отвечать на `OPTIONS` пустым 204 с теми же заголовками.
3. Добавить действие `get&id=…`, которое отдаёт событие с пунктами — из него
   lite собирает отметки.
